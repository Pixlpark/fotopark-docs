# Разметка макетов в редакторе

* Разметка макета позволяет связать элементы дизайна с данными выпускного альбома и настроить их автоматическое заполнение при его формировании. С помощью мета-тегов текстовые и графические элементы макета связываются с информацией об учебном заведении, классе, учениках, учителях и других участниках альбома.
* В данном разделе описаны доступные мета-теги, их назначение, структура групп и правила использования при создании и разметке макетов.

## Группы и мета-теги 
:::info[Информация]
* Группа - определяет, кому принадлежит информация
* Мета-тег - определяет, что это за фотография/текст и для чего она используется.
:::
### Для изображений
+ __Уч. заведение__ - группа, содержащая информацию об учебном заведении.
	+ __Фотография__ - фотография учебного заведения: здание школы, лицей, детский сад и т. п. Используется для оформления страниц, связанных с учебным заведением.  

+ __Класс__ - группа, содержащая информацию о классе/группе
	+ __Общее фото учеников__ - общая фотография класса/группы, на которой изображены все или большая часть учеников класса. Используется как групповая фотография класса/группы.  
	+ __QR-код оживающих фото__ - изображение QR-кода для скачивания приложения/программы, необходимой для просмотра оживающих фотографий 

+ __Текущий ученик__ - группа, содержащая информацию об ученике, для которого формируется выпускной альбом 
	+ __Портрет на обложку__ - фотография текущего ученика, предназначенная для размещения на обложке выпускного альбома. 
	+ __Персональный портрет__ - индивидуальный портрет текущего ученика, используемый на персональных страницах альбома. 
	+ __Репортажное фото__ - фотография текущего ученика в процессе деятельности или в естественной обстановке: на уроке, мероприятии, прогулке, празднике и т. п. Используется для наполнения персональных страниц альбома. 
	+ __Фото подписи__ - фотография или скан рукописной подписи текущего ученика. Используется для размещения подписи в альбоме. 
	+ __Избранное фото__ - фотография текущего ученика, выбранная как основная/предпочтительная для использования в соответствующих макетах альбома. 

+ __Одноклассники / Виньетка__ - группа, содержащая информацию об учениках класса для формирования виньетки. 
	+ __Портрет__ - индивидуальный портрет ученика, предназначенный для размещения на виньетке. 
    + __Фото подписи__ - фотография или скан рукописной подписи ученика, предназначенная для размещения на виньетке. 
    + __Избранное фото__ - выбранная фотография ученика, которая используется в макетах, где требуется его дополнительное изображение. 

+ __Учитель__ - группа, содержащая информацию об учителе 
    + __Портрет__ - индивидуальный портрет учителя, предназначенный для размещения в альбоме. 
    + __Подпись__ - фотография или скан рукописной подписи учителя. 
    + __Избранное фото__ - выбранная фотография учителя для использования в соответствующих макетах альбома. 

+ __Кл. руководитель__ - группа, содержащая информацию о классном руководителе
    + __Портрет__ - индивидуальный портрет классного руководителя, предназначенный для размещения в альбоме. 
    + __Подпись__ - фотография или скан рукописной подписи классного руководителя. 
    + __Избранное фото__ - выбранная фотография классного руководителя для использования в соответствующих макетах альбома. 

+ __Директор__ - группа, содержащая информацию о директоре учебного заведения. 
	+ __Портрет__ - индивидуальный портрет директора, предназначенный для размещения в альбоме. 
    + __Подпись__ - фотография или скан рукописной подписи директора. 
    + __Избранное фото__ - выбранная фотография директора для использования в соответствующих макетах альбома. 


### Для текста
+ __Уч. заведение__ - группа, содержащая информацию об учебном заведении. 
	+ __Наименование__ - полное название учебного заведения. Например: «МАОУ Лицей № 5» 
	+ __Город__ - название города, в котором находится учебное заведение. 
	+ __Примечание__ - дополнительная информация об учебном заведении, которая может использоваться в макетах альбома. 

+ __Класс / Группа__ - группа, содержащая информацию о классе/группе 
	+ __Номер и буква / название__ - обозначение класса одной строкой: номер и буква класса без разделения (например, «11А») или название учебной группы. 
	+ __Номер класса__ - номер класса (например, «11») или название учебной группы.
	+ __Буква класса__ - буквенное обозначение класса (например, «А», «Б», «В»). 
	+ __Количество учеников__ - количество учеников в классе или учебной группе. 
	+ __Год выпуска полностью__ - год выпуска в полном формате, например «2026». 
	+ __Год выпуска сокращенно__ - последние две цифры года выпуска, например «26». 
	+ __Профиль класса__ - профиль или специализация класса, например «физико-математический», «гуманитарный», «медицинский». 
	+ __QR-код инфо__ - текстовое описание о том, как использовать сервис оживающих фотографий. Отображается только в том случае, если для класса задан QR-код. 

+ __Учитель__ - группа, содержащая информацию об учителе 
	+ __Имя__ - имя учителя 
	+ __Фамилия__ - фамилия учителя
	+ __Отчество__ - отчество учителя 
	+ __Имя и отчество__ - имя и отчество учителя, объединённые в одну строку. 
	+ __Фамилия Имя Отчество__ - фамилия, имя и отчество учителя, объединённые в одну строку. 
	+ __Цитата__ - цитата, высказывание или пожелание учителя, предназначенное для размещения в альбоме. 
	+ __Должность__ - должность учителя, например «Учитель математики». 

+ __Текущий ученик__ - Группа, содержащая информацию об ученике, для которого формируется выпускной альбом. 
    + __Имя__ - имя текущего ученика
	+ __Фамилия__ - фамилия текущего ученика
	+ __Имя и фамилия__ - имя и фамилия текущего ученика, объединённые в одну строку. 
	+ __Цитата ученика__ - цитата, высказывание или пожелание текущего ученика, предназначенное для размещения в альбоме. 

+ __Одноклассники__ - группа, содержащая информацию об учениках класса для формирования виньетки. 
    + __Имя__ - имя ученика
	+ __Фамилия__ - фамилия ученика
	+ __Имя и фамилия__ - имя и фамилия ученика, объединённые в одну строку. 
	+ __Цитата ученика__ - цитата, высказывание или пожелание ученика, предназначенное для размещения в альбоме. 

+ __Кл.руководитель__ - группа, содержащая информацию о классном руководителе
    + __Имя__ - имя классного руководителя
	+ __Фамилия__ - фамилия классного руководителя
	+ __Отчество__ - отчество классного руководителя
	+ __Имя и отчество__ - имя и отчество классного руководителя, объединённые в одну строку. 
	+ __Фамилия Имя Отчество__ - фамилия, имя и отчество классного руководителя, объединённые в одну строку. 
	+ __Цитата__ - цитата, высказывание или пожелание классного руководителя, предназначенное для размещения в альбоме.  
	+ __Должность__ - должность классного руководителя. 
 
+ __Директор__ - группа, содержащая информацию о директоре учебного заведения
	+ __Имя__ - имя директора 
	+ __Фамилия__ - фамилия директора 
	+ __Отчество__ - отчество директора 
	+ __Имя и отчество директора__ - имя и отчество директора, объединённые в одну строку. 
	+ __Фамилия Имя Отчество__ - фамилия, имя и отчество директора, объединённые в одну строку. 
	+ __Цитата__ - цитата, высказывание или пожелание директора, предназначенное для размещения в альбоме. 
	+ __Должность__ - должность директора

+ __Элемент дизайна__ - группа, содержащая информацию об элементах дизайна и служебных параметрах макета. 
	+ __Номер страницы__ - номер страницы альбома, на которой находится элемент. Используется для автоматического отображения номера страницы в макете.
